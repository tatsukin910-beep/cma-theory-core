# CMA Theory Core

Complex Multilayered Abuse (CMA) の正本定義文書および関連用語を管理するリポジトリです。

CMAは診断・治療・スコアリングを目的としない非診断的構造記述ツールです。本リポジトリは、定義の改訂履歴を透明に保持し、研究上の検証可能性を確保することを目的とします。

## 内容

現行の正本テキストは、このリポジトリの Release からは作っていません。

- Theory Definition v2.0 は、手動アーカイブとして Zenodo に固定済みです。引用可能な正本はこの PDF です。
- 用語規範は Official Terminology v1.0.1 です。本リポジトリ内のノートではありません。
- `docs/` は、手元の定義 Markdown を置く場所です。ファイルを追加するまでは、上記 Zenodo の PDF を正本とします。

次回以降の改訂から、区切りのよい時点で GitHub Release を作成し、Zenodo の GitHub 連携で新しいバージョンとしてアーカイブします。v2.0 と同じ内容の Release は作りません。既存の DOI と重複させないためです。
